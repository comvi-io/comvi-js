Fix type resolution for CJS consumers, fix CJS bundle extension, and align package metadata.

- Add nested per-condition `types` keys to all `exports["."]` conditions (`import`, `require`, `production.import`, `production.require`). The `require` conditions now point at `.d.cts` siblings generated by the post-build emit tool, so CJS consumers receive correctly-resolving declarations. The top-level `types` field is retained for legacy resolvers.
- Rename CJS bundle outputs from `.cjs.js` to `.cjs` (vite config `fileName` and all `require.default` / `production.require.default` export paths, plus `main`). Under `"type":"module"`, the previous `.cjs.js` extension was interpreted as ESM by Node and bundlers, breaking `require()` consumers. The standalone IIFE (`.iife.js`) and ESM (`.es.js`) outputs are unchanged.
- Add `engines.node: ">=22"` to match the workspace root constraint.
- Fix `repository.url` to include the required `git+` prefix.
