The inline catalog module option is `comvi.messages`, published as `runtimeConfig.public.comvi.messages`, so `NUXT_PUBLIC_COMVI_MESSAGES` overrides it. The server util is `loadMessages()` with `LoadMessagesOptions` and a `MessagesMap` result; `comvi.translation` and `loadTranslations()` are removed.
