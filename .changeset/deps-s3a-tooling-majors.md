The packages are now built and tested with the next major versions of the development toolchain (Vitest 5, vite-plugin-dts 5, Prettier 3.9, Tailwind CSS 4.3, React 19.3 types). Runtime and peer dependency ranges and the API are unchanged. Two outputs read differently and behave the same: the `I18nProvider` declarations of `@comvi/react` and `@comvi/next` name their return type `import('react').JSX.Element` instead of `import("react/jsx-runtime").JSX.Element` (the same type; both forms need `@types/react` 18.2.7 or later, as before), and the in-context editor's bundled stylesheet is regenerated by Tailwind CSS 4.3 with equivalent rules.
