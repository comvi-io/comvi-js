`useI18n(ns)` returns `isReady` beside `isLoading`, both from the render's state: `isReady` when a catalog of the locale on screen, its parent or an allowed fallback locale is in (inline, cached, handed over or loaded; an empty one too), `isLoading` while one loads or the hook's hold will load one — so the first render already says "loading", never "unavailable"; a failed load is `false`/`false`. The hook holds its namespace from its commit to its cleanup (an effect: a render React abandons holds nothing, Strict Mode counts right, a new `ns` swaps the hold); with no component holding it, a switch does not load it. `<T>` (also `<T ns>`) reads only and loads nothing; `useI18n(ns).T` reads the namespace its `useI18n` holds. The first-paint gate (`loading`, `suspense`) opens on the core's `isReady`: a catalog of a locale outside the chain no longer opens it (`locale: "uk"` with only `en` messages and no `fallbackLocale` shows the placeholder while `uk` loads).
