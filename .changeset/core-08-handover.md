`handover(i18n)` on `@comvi/core/internal` (re-exported by `@comvi/vue`): what a server render gives the browser — the locale, `timeZone`, the clock and the catalogs of every active namespace in the locale's chain, in the shape of `createI18n({ catalogs })`; a slot of the chain whose load failed is handed over as `null`, so the browser renders the fallback the server rendered and does not ask for it while it hydrates; an explicit `i18n.load(ns)` (or a switch to that locale) asks for it again. `createI18n({ catalogs })` takes such a `null` slot. A development build throws when the instance has no `timeZone`. On a server (no `document`), an instance without a `now` option reads the clock once and keeps that reading: `formatRelativeTime` and `handover()` count from the same instant, so the browser formats what the server formatted. The component types `TComponentFor` and `BoundTFor` take an optional flag that makes `Tag` params optional props, for a binding whose `<T>` also takes a tag handler from a slot (Vue); the typo guard is the same.
