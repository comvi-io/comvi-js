**BREAKING** — `@comvi/react` is rebuilt on the 0.8 core. `createI18n` (re-exported from `@comvi/core`) makes the instance; `<I18nProvider i18n>` gives it to the tree, with `loading` (rendered while a catalog of the current locale loads) or `suspense` (suspends on `i18n.ready`; a re-render while the loads are in flight does not suspend again). `useI18n(ns?)` returns `t`, `locale`, `dir`, `isLoading`, `setLocale` and the instance; `ns` binds `t` and is loaded after commit, never during render. `useLocale()` re-renders on a locale change only, not on a namespace load. `<T i18nKey ns? locale? {...params}>` renders a message; a tag handler is a prop of the tag's name and receives its children as one React node (`link={(c) => <a href="/terms">{c}</a>}`), so nested tags and element params render without React key warnings. A handler that returns `null`/`undefined` renders nothing; a throwing handler throws to the app's error boundary. `<I18nHandover catalogs locale>` renders its subtree with server-provided catalogs and a target locale at once and hands both to the instance only at commit, so an abandoned, suspended or server render changes nothing. `useFormat()` from `@comvi/react/format` formats numbers, currency, dates, ranges, lists, display names and relative time in the locale on screen. Removed with the 0.7 core: the capability hooks, `useI18nLoader`, `useSetLocaleTransition` (use `isLoading` and `startTransition`), `useIsLoading`, the provider's `autoInit`/`fallback`/`ssrLocale`/`targetLocale`/`messages` props (→ `loading`, `suspense`, `<I18nHandover>`), `tRaw`, `hasTranslation` (→ `i18n.has`), and `<T components>` (→ handler props). A development build (`development` export condition) explains a hook used outside a provider; the production build ships no diagnostic text.
