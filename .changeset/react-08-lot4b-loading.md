`<I18nProvider loading | suspense>` gates the first paint only while a namespace being loaded has no catalog of any locale (inline `messages` or a fallback locale's catalog show at once), and opens when a render without it COMMITS, so a render React abandons changes nothing. A server render and a hydration always render the children, so an `<I18nHandover>` hydrates at any depth (a Fragment, a layout, a `<Suspense>`) with no mismatch and no request for its payload. `useI18n()` without a namespace activates `default` too, so an app whose `namespaces` option leaves it out loads it on first use instead of showing it as loading forever. `useFormat()` activates no namespace, and relative time counts from a handed-over `serverNow` only in a component's hydration render (a Suspense boundary hydrated later too) and from the browser clock in every other render, a component mounted after the hydration included. While `loading` shows on a client render, the children are mounted hidden beside it (`<b hidden>`): their effects run, an `<I18nHandover>` at any depth among them hands its catalogs over at commit and can open the gate at once, and when the gate opens they mount again in place. `suspense` mounts nothing while it suspends, so a handover below it waits for the loads.
