**BREAKING** (0.8-internal) — loading contracts. `setLocale(l)` waits for the namespaces active when it is called; one activated while it is pending loads for the locale on screen, then for `l` right after the switch. A later call wins: an earlier one never switches once a later one exists, and its promise resolves (it does not reject) once its loads settle or are aborted; the latest call rejects only when no namespace it waited for has a catalog of `l`'s own chain. `load(ns)` now rejects with the loader's error by the same rule (it used to resolve when its load failed) and resolves `undefined` otherwise, also when a switch aborted it; a binding's automatic activation never rejects. `t()` of a namespace still loading returns what a missing key returns, unreported. `handover()` emits the server clock as `serverNow` (was `now`): `createI18n({ ...payload })` formats relative time from it; a binding's `useFormat()` counts from it only for a component's hydration and from the browser clock for every other render (a component mounted later included); an explicit `now` option stays fixed. A tag handler gets the text of its tag's content as a second argument, on demand (`(children, text) => …`: the message's text with no handler run — what a Vue slot receives). A plugin's `setup(i18n, mark)` receives the setter of the in-context editor's marking hook (the `/devtools` plugin hands it to the editor); `@comvi/core/internal` exposes the binding seam `core(i18n)` and `clock(i18n, live)`, none of them a way to mark. In production the `RangeError` of an invalid `setLocale()` tag carries the tag only.
