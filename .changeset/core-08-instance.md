**BREAKING** — `createI18n(options)` returns the 0.8 instance: synchronous construction (no `init()`), exactly thirteen members — `locale`, `dir`, `ready`, `t`, `ns`, `setLocale`, `load`, `add`, `has`, `on`, `rev`, `destroy`, `setDefaultParams` — over one immutable state that `on()` subscribers are told about on every change. Options: `locale`, `fallbackLocale` (one, a list, or lists per locale with a `default`), `messages` (the `default` namespace) and `catalogs` (by namespace), `loader(locale, ns, signal)`, `namespaces`, `defaultParams` (copied: each published state keeps its own), `plugins`, `timeZone`, `now`, `formats`, `onError`, `missing`. `t(key, { ns, locale, ...params })` switches namespace and locale per call (`ns` and `locale` are reserved names, never message params); `i18n.ns("shop")` binds a namespace; the `"ns:key"` spelling is gone. A locale falls back through its parents (`pt-BR` → `pt`) and then `fallbackLocale`; an empty translation counts as missing. Catalogs are flat and kept by reference; `add()` over an existing catalog writes a patch layer instead of copying it, and adding the catalog a pair already holds changes and publishes nothing. Loads are deduplicated per locale and namespace, and `setLocale()` switches inside the call when nothing has to load, otherwise once its loads settle — a namespace that fails to load (a 404 for one file) no longer blocks the switch, nor does a missing regional file when its parent loads (`pt-BR.json` 404, `pt.json` 200); only a locale with no catalog of its own chain at all rejects. A namespace loaded while a switch is pending is loaded for the new locale too. `ready` is one promise for as long as the set of loads in flight does not change. Malformed locales are reported as `invalid_locale` before anything renders or loads. Every problem is an `onError` report with a code: `missing_key`, `missing_param`, `syntax`, `load_failed`, `invalid_locale`, `fallback_used`; an `onError` that throws never breaks a render or a load (its error is rethrown asynchronously). The default reporter prints each problem once per process in development — on a development SSR server, once for all requests. New subpaths: `@comvi/core/cdn` (`cdn(base)` reads the Comvi CDN exactly as `@comvi/plugin-fetch-loader`'s CDN loader did; `cdn(base, { fallback: { de: () => import("./locales/de.json") } })` serves bundled catalogs when the CDN cannot answer, never on an abort; `root: false` puts every namespace in its own folder), `@comvi/core/plugins` (`plugins: [detect({ supported })]` starts in the locale the URL, cookie, storage or browser names, before anything loads; `persist()` saves every switch), `@comvi/core/format` (`formatNumber`, `formatCurrency`, `formatDate`, `formatDateRange`, `formatRelativeTime(i18n, date, now?)`, `formatList`, `displayName`; `formatNumber`/`formatDate` take the name of a `formats` entry) and `@comvi/core/devtools` (`plugins: [devtools()]` makes the instance discoverable by the Comvi browser extension, which loads the in-context editor on request). `@comvi/plugin-fetch-loader` and `@comvi/plugin-locale-detector` are superseded by `/cdn` and `/plugins`.
