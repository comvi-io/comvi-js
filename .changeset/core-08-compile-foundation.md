**BREAKING** — the 0.8 rebuild of `@comvi/core` starts: the message compiler and the locale module are new. Messages use one grammar, ICU MessageFormat as ICU4C reads it: `plural`, `selectordinal`, `select`, `=N`, `offset:` and `#`, with ICU apostrophe quoting, and rich-text tags (`<b>…</b>`, `<br/>`) are always recognized. `#` is the count only in a plural's own sub-messages; inside a `select` nested in a plural it is a literal `#`, as in ICU4C, and development builds warn about it once per key and locale. A plain `{x}` prints `String(value)` for every type, as in 0.7: `{orderId}` with `1004` prints `1004` and `{year}` with `2026` prints `2026`, never `1,004`; a `Date` and a list of strings, numbers or dates print as `String()` prints them (`[1, 2]` → `1,2`); functions, other objects (framework nodes) and a list holding one pass through for the binding to render. Format a number or a date for the locale in code with `@comvi/core/format` and pass the string; `#` in a plural is the one value the compiler formats for the locale. `{x, number}`, `{x, date}` and `{x, time}` are not supported: they report a `syntax` error whose message, in production too, says to format the value in code with `useFormat()`. A `plural` or `selectordinal` count is a number; a numeric string such as `"5"` or `" 2.5 "` is converted with `Number()`, as in 0.7. A blank or non-numeric string, `NaN`, a missing value or any other type renders `{n}` and reports `missing_param`. Parameters and tag handlers are read from the params object's own properties only, so a message naming `{toString}` or `<valueOf>` never reaches `Object.prototype`. A message that does not compile renders its key and reports `syntax` instead of throwing. Locales are canonicalized (`en_US` → `en-US`, `iw` → `he`), fall back through a parent chain that never crosses scripts (`zh-HK` never reaches `zh`), and `negotiate()` picks the best supported locale for a list of requested ones. The 0.7 subpaths `/icu`, `/loader`, `/rich-text`, `/tags` and `/editor-bridge` and the CDN global build are removed; `/plugins` and `/devtools` are new subpaths of the same names (see the instance changeset).
