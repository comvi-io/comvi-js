# Limitations

The list of what Comvi i18n does not do or does not verify is one public page:
**<https://comvi.io/docs/i18n/limitations>**. Every package README links to it.

This file is only a pointer, so that the repository and the site cannot disagree. The 0.5–0.7 copy
that lived here is in git history. The reasoning behind individual limits is in the design records:
[icu.md](icu.md) (message syntax), [formatting.md](formatting.md), [rich-text.md](rich-text.md),
[namespaces.md](namespaces.md), [ssr.md](ssr.md) and [editor-loader.md](editor-loader.md).
