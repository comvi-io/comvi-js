## Decisions taken in 1a (for the reviewer)

- Syntax errors (unclosed `{`, missing `other`, bad selector, unclosed or crossing tags,
  `{x, number|date|time}`) render the KEY and report `syntax` on every render, through the env of
  the rendering instance (the compiled record is shared, R4-2). Without a key (direct `compile`),
  the template itself.
- A plural/selectordinal count must be a number (ICU4C rejects anything else): a numeric
  string, NaN or a missing value renders `{n}` and reports `missing_param`. 0.7 accepted
  `Number(value)`.
- A missing `select` value reports `missing_param` and renders the `other` branch.
- A repeated selector keeps its first sub-message (ICU4C).
- Plain `{x}` with a Date prints ICU's `{0}` form: short date + short time (DateTimeFormat
  `dateStyle: "short", timeStyle: "short"`) in the env's time zone.
- Tag children reach the handler as an array (`Tag = (chunks: RichParts) => unknown`); a handler
  result that is not a string is one rich part. The 0.7 backslash escape `\<` is gone; quote
  with `'<'` (ICU apostrophe rules).
- `negotiate(requested, supported, fallback?)` returns the supported entry as the caller spelled
  it, or `fallback` (undefined when absent).

## Left for 1b by the 1a review (27.10)

- **Locale at the render boundary (R3-1, R4-10).** A malformed or empty locale (`""`, `"!!"`)
  makes the `Intl` constructors in `fmt.ts` / `icu.ts` throw out of `render()`. At 1a it is
  reachable only through `/internal`; 1b's per-call `{ locale }` comes from user input, so 1b
  canonicalizes it (or reports `onError({ code: "invalid_locale" })` and falls back) BEFORE
  `render`, with a red test seen failing first.
- **Layered `add()` (R4-1b).** `inherit(prev, prevRecord, next)` in `cache.ts` is O(|prevRecord|)
  and assumes a fully spread `next` catalog: that is the FLATTEN path (after 256 patched keys).
  The `{m, c, p, pc}` layered patch slot, which keeps `add()` ≤ 100 µs on a 10K catalog (synthesis
  4.5; COW measured 4.2–4.7 ms), is 1b work, with its own counted gate (no wall clock in unit tests).
- **Catalog keys and CDN URLs keep the app's spelling.** `canonicalize("iw")` is `"he"` (§1.5
  golden table), but the platform canonicalizes separator and case only. `cdn()` URLs and
  catalog keys use the app's / `supported` spelling, never the canonical form — as `negotiate`
  already returns the supported entry as spelled (R4-10 parity).
- **Tag handler results (1c).** A handler that returns `undefined`/`null` yields `[undefined]`
  in the rich parts, and a function passed as a plain `{x}` value passes through as a rich part
  (0.7 rejected one even with VNode-shaped fields). The React binding (1c) decides: warn, drop,
  or render nothing — React itself warns on function children.
- **The S3 gate of synthesis 4.5.** `diff.mjs` (360) / `extra.mjs` (30) is superseded by the
  `icu4c.json` (ICU4C 78, the reference after R3-8) and `formatjs.json` (the S3 subset for the
  supported grammar) golden tables in `packages/core/tests/golden/`; it is not missing.
- **Owner nod needed.** A `plural`/`selectordinal` count must now be a number (ICU4C rejects
  anything else); 0.7 accepted `Number("1")`. The changeset says so; keep or restore coercion
  per the owner's answer.
